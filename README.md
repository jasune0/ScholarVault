<h1>ScholarVault</h1>
<p>A full stack web application that helps students, researchers and librarians effciently discover, filter and organics scholary sources through CrossRef REST API.</p>

<h2>Features</h2>
<ul>
  <li><strong>Keyword Search</strong> - search any topic, author, or paper title across 150M+ works</li>
  <li><strong>Filters</strong> - filter by type (journal articles, conference papers), year range, open access, and sort by relevance or citation count</li>
  <li><strong>Paper Detail Page</strong> -  view full metadata including abstract, authors, journal, citation count, DOI, publisher and volume</li>
  <li><strong>Save Papers</strong> - save papers to a library that persists in a supabase database(are no personal libraries at the moment)</li>
  <li><strong>Personal Notes</strong> - attach your own notes to any saved paper</li>
</ul>
